One original line roasting a gadget used every day — a smartwatch that treats standing up like a crime it just caught you committing. The program writes the roast to `entry.txt` for make.fun's "One-Line Roast: The Gadget You Use Every Day" bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/roast-out node main.ts
```
